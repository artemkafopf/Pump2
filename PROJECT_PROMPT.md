# Project Prompt

```text
Нужно создать полный проект с нуля в папке проекта.

Стек:
- backend: Python + FastAPI
- frontend: Vue 3
- база данных: PostgreSQL
- оркестрация: docker-compose
- аналитическая модель: CatBoost

Общие требования:
- проект должен запускаться через docker-compose
- backend, frontend и postgres должны быть разнесены по отдельным сервисам
- frontend должен быть адаптивным
- загруженные данные должны храниться в Postgres
- загруженная таблица должна сохраняться без модификации:
  - все заголовки как есть
  - все строки как есть
  - значения не нормализовать и не переписывать при сохранении
- весь код должен быть рабочим и сразу запускаться после сборки контейнеров
- после изменений нужно пересобирать и проверять проект

Backend:
- реализовать API на FastAPI
- сделать endpoint загрузки Excel файла (.xlsx, .xls)
- при загрузке:
  - считывать Excel
  - сохранять исходные заголовки
  - сохранять строки таблицы в БД без изменения структуры
- сделать сущность dataset и хранить:
  - id
  - имя набора
  - имя исходного файла
  - список колонок
  - target_column
  - selected_features
  - количество строк
  - дату создания
- сделать API:
  - список наборов данных
  - получение конкретного набора данных
  - обновление выбора целевой и зависимых переменных
  - получение аналитики по набору
- аналитика должна использовать CatBoostRegressor
- CatBoost должен строиться по:
  - target_column как целевая переменная
  - selected_features как признаки
- если selected_features пуст, использовать все колонки кроме target
- backend должен возвращать:
  - overview
  - correlations
  - feature importance
  - numeric_columns
  - categorical_columns
  - datetime_columns
  - notes
- корреляции считать по числовым признакам с target
- важности признаков считать через CatBoost
- код backend должен быть разложен по модулям: db, models, schemas, api, services

Frontend:
- сделать SPA на Vue 3
- главный экран должен содержать:
  - загрузку Excel
  - список загруженных наборов
  - панель выбора переменных
  - блок аналитики
  - таблицу с исходными данными
- для загрузки Excel:
  - кнопка открытия проводника
  - ввод названия набора
- после загрузки файла:
  - распознать заголовки
  - показать выбор колонок кнопками
- выбор переменных:
  - целевая переменная выбирается отдельным блоком кнопок
  - зависимые переменные выбираются отдельным блоком кнопок
  - target не должен одновременно попадать в dependent variables
  - основную кнопку назвать: "Запустить аналитику CatBoost"
- после сохранения выбора:
  - заново запрашивать анализ
  - обновлять дашборд

Дашборд:
1. Сводка
- число строк
- число колонок в анализе
- valid target rows
- среднее target
- доля пропусков
- заметки backend

2. Feature importance
- горизонтальный bar chart по CatBoost importance

3. Корреляционная матрица
- heatmap корреляций признаков с target
- в ячейках должны быть подписи значений корреляции

4. Целевая переменная во времени
- отдельный график
- пользователь выбирает колонку по оси X кнопками
- ось X не форматировать как date-type Plotly
- использовать обычные значения X
- осреднение по Y делать без учета нулей и пустых значений
- добавить группировку по другим переменным как срезы
- добавить фильтр по годам через временную шкалу/ползунки:
  - год от
  - год до
- для этого графика строить осреднение по годам
- справа от графика показывать таблицу:
  - колонки = годы
  - строки = элементы выбранной группировки
  - значения = среднее target по году
  - нули не учитывать
  - округление до десятых

5. Scatter plot
- выбор оси X и Y кнопками
- ползунки минимум/максимум по X и Y
- раскраска точек по выбранной переменной
- поверх точек добавить линию осреднения:
  - усреднение по Y
  - нули и пустые значения Y не учитывать
  - окна по X с шагом 10% диапазона X
- у усредненных точек должны быть подписи X и Y
- рядом вывести таблицу осредненных значений:
  - окно X
  - средний X
  - средний Y
  - число точек
  - округление числовых значений до десятых
- слева от таблицы осреднения вывести отдельный график усредненных точек X-Y

6. Тепловая карта
- heatmap по выбранным осям scatter
- режим раскраски:
  - плотность точек
  - среднее по одной выбранной переменной

7. Гистограммы
- построение по любой переменной
- прозрачность столбцов 60%
- возможность строить несколько гистограмм на одном графике по срезам
- добавить отдельный срез "Год"
- должна быть возможность:
  - смотреть один год
  - смотреть несколько лет отдельно
  - смотреть несколько выбранных лет вместе
- для годового среза добавить переключатель объединения выбранных лет
- для остальных срезов также оставить возможность агрегированного показа "вместе"

UI/UX:
- адаптивная верстка
- графики должны подстраиваться под ширину экрана
- таблицы должны иметь horizontal scroll при необходимости
- кнопки-срезы должны быть удобны и на десктопе, и на мобильных
- использовать Plotly для графиков
- стиль должен быть современный, чистый, без перегруза

Технические требования:
- не использовать заглушки
- если делаешь правки, сразу вносить их в код
- после реализации обязательно:
  - пересобрать frontend/backend через docker compose
  - проверить, что frontend открывается
  - проверить, что backend отвечает
- при проблемах исправлять код, а не останавливаться на анализе

Если в текущей реализации есть риск runtime-ошибок во Vue:
- не оставлять в шаблоне ссылки на несуществующие computed/ref
- не использовать переменные в watch до их объявления
- избегать рекурсивных computed/watch зависимостей

Нужен именно рабочий проект, а не черновой каркас.
```
