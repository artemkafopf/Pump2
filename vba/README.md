# ESP VBA Prediction Modules v2 — Setup Guide

Aligned with Phases A–D (`results/model_report/2026-07-07/README.md`).
Spec: `agents/analyses/vba_model_v2.md`. What changed and why: see
`results/vba_model_v2/<date>/README.md`.

## What v2 changes (read before importing)

| # | v1 (stale) | v2 (this build) |
|---|---|---|
| Population | failures-only fits | **full population** (2,634 runs) — B50s roughly 2× larger |
| Clock | calendar days | **operating time (`ttf_mix`)** — every time output header carries `_op_d` |
| θ layer | 3-covariate Cox applied to every row | **shelved** (failed the out-of-sample gate). `ESP_*_Cox` return the baseline unless explicitly re-enabled |
| Degenerate strata | K=2 numbers kept, flagged | stored as `w1=0` single Weibull + `model_kind` (`k2`/`k1_aic`/`k1_degenerate`) |
| Planning | none | **mode-mix layer** (`ESP_ModeMix`) + per-mode incidence UDFs |
| Registry | positional CSV | **header-driven**, refuses a non-`ttf_mix` file |

**Clock caveat (§0.1 document-only):** ages and RULs are in **operating days**,
not calendar days. The workbook's age column (I) is calendar days — feeding it
directly overstates a pump's age. `ESP_Uptime` returns the per-stratum uptime
factor `u_s = mean(ttf_mix/run_days)` so you can convert manually
(`age_op ≈ age_cal × u_s`, `RUL_cal ≈ RUL_op / u_s`).

## First-time setup

1. **Back up** the production `.xlsm` and stage the upgrade in a copy first.
2. Open the workbook as `.xlsm`, Alt+F11.
3. **Remove old modules first** (right-click → Remove → No to export), then Import —
   this avoids stale-module ghosts (`mdlFoo1`). Remove any pre-v2 `mdlCoxHR`
   and delete the old `ESP_CoxCoeffs` sheet.
4. Import: `mdlMath`, `mdlLatentWeibull`, `mdlModelRegistry`, `mdlModeMix`,
   `mdlPublicFunctions`, `mdlCoxHR`, `mdlHazardLayer`, `mdlBatchProcess`,
   `mdlValidation`, `mdlModelSeed` (the generated one).
5. Paste `ThisWorkbook_setup.bas` into the `ThisWorkbook` code module.
6. **Import the bundle** (Immediate window, Ctrl+G):
   ```
   ImportBundle "D:\GitHub\Pump2\results\esp_survival_vba_models\YYYY-MM-DD"
   ```
   This loads `ESP_Models`, `ESP_ModeMix`, `ESP_ModeMap` (audit), and the hidden
   `ESP_Version` sheet. (Offline fallback: `CreateModelSheet` from `mdlModelSeed`.)
7. **Validate:** run `ValidateRegistry` — the `ESP_Validation` sheet must be
   all-green.
8. **Predict:** run `RunPredictions` (fills columns BY–CN).

## Worksheet UDF reference

All time inputs/outputs are **operating days**.

| Formula | Description |
|---|---|
| `=ESP_RUL(I2, A2, BW2, D2)` | Remaining life (operating days) |
| `=ESP_B50(A2, BW2, D2)` | Median TTF (operating days) |
| `=ESP_B20 / =ESP_B80` | 20th / 80th percentile TTF (replaced B10/B90) |
| `=ESP_TTF_Mean(A2, BW2, D2)` | Mean TTF (closed form) |
| `=ESP_SF(I2, A2, BW2, D2)` | S(t) at current age |
| `=ESP_Hazard(I2, A2, BW2, D2)` | Hazard rate at current age |
| `=ESP_Component(I2, A2, BW2, D2)` | C1 (early) / C2 (wear-out) |
| `=ESP_Stratum(A2, BW2, D2)` | Resolved stratum key (audit) |
| `=ESP_ModelKind(A2, BW2, D2)` | `k2` / `k1_aic` / `k1_degenerate` |
| `=ESP_IsDegenerate(A2, BW2, D2)` | TRUE only for `k1_degenerate` |
| `=ESP_Uptime(A2, BW2, D2)` | Uptime factor u_s (manual clock conversion) |
| `=ESP_RunSeq(<well cell>)` | Run sequence number on that well (flag) |
| `=ESP_Predict(I2, BX2, A2, BW2, D2)` | RUL if running, B50 if failed |
| `=ESP_ModeShare(A2, BW2, D2, "electro-thermal", 365)` | Incidence share by mode at 90/365 op-d |
| `=ESP_ModeIncidenceTime(A2, BW2, D2, "hydraulic", 10)` | Op-days to 10%/25% cumulative incidence |
| `=ESP_DominantMode(A2, BW2, D2, I2)` | Dominant near-term failure mode (planning) |
| `=ESP_HazardFlags(<well cell>, <run_seq cell>)` | Advisory: modes a run's operating covariates elevate (display-only) |
| `=ESP_HazardTheta(<well cell>, <run_seq cell>)` | Hazard multiplier (=1 while the layer is shelved) |

Column map (data sheet `Свод`): **A**=Field, **D**=Contractor, **I**=Age (op-d
assumed), **BW**=H2S class, **BX**=Failure flag (0=running, 1=failed, -1=suspended).
UDFs accept the raw Russian cell values **or** the Latin codes
(`brt`/`slb`/`oth`/`Pooled`, `sour`/`nonsour`) directly.

θ is shelved: `ESP_Theta` returns 1 and `ESP_B50_Cox` etc. equal the baseline
unless an `ESP_CoxCoeffs` sheet with `enabled=TRUE` is present (Phase E re-enable
path — see the header of `mdlCoxHR.bas`).

## Operational + completion + cohort hazard layer (SENSITIVITY — not OOS-validated)

Seven hazard groups (GLF, load, kpod, frequency, curvature-value, well_history,
vintage) are imported by `ImportBundle` into `ESP_CoxCoeffs` (coefficients +
`hazard_group` + `enabled`) and `ESP_RunCov` (per-run covariates, joined on the
normalized well name + run sequence). Module: `mdlHazardLayer.bas`.

**Enabled at the user's request as a physical what-if / regime-sensitivity tool — it
is NOT a validated forecast.** The subset failed the out-of-sample gate (it
discriminates *worse* than the stratum baseline OOS — see
`results/vba_model_v2_hazards/<date>/README-data.md` and model report §3.8/§8.5),
and the **cohort groups (`well_history`, `vintage`) generalize the least**. So:

- The **baseline** columns (`ESP_B50_op_d`, `ESP_RUL_op_d`, …) are **never altered** —
  the stratum + K=2 baseline stays the reference forecast.
- `ESP_RUL_sens_op_d` / `ESP_B50_sens_op_d` apply the full θ (η-rescaled via
  `ApplyCoxEta`), so RUL responds to operating regime, well history and vintage.
- `ESP_dRUL_*` give the **one-group-at-a-time marginal** shift per factor (not
  additive — θ is multiplicative on the hazard; the per-group deltas are single-factor
  what-ifs, `ESP_RUL_sens` is the combined effect).
- `ESP_dRUL(field,h2s,ctr,age,<well cell>,<run_seq>,"kpod")` and
  `ESP_dB50(...,"vintage")` compute any group's delta ad hoc.

Curvature uses the value (°/10 m), missing → 0.0 (straight well). Operational groups
need early-window telemetry (their Δ is 0 for pumps with <30 op-days); curvature,
well_history and vintage apply to essentially every run. To turn the overlay off,
set the `enabled` column in `esp_cox_coeffs.csv` to FALSE and re-import → every θ and
Δ collapses to 1/0 and only `ESP_HazardFlags` remains.

## VBA rules honored (each cost a session before)

- `ChrW()` (not `Chr()`) for Unicode; source `.bas` files contain no Cyrillic literals.
- `mLoaded/mCount/mModels` are Private to `mdlModelRegistry`; other modules go
  through `EnsureRegistryLoaded()` / public accessors only.
- No name collides case-insensitively with a function.
- **No `MsgBox` in any UDF-reachable path.** Import/validation results go to the
  `ESP_Status` / `ESP_Validation` sheets.
- Remove the old module before re-importing (stale-module ghosts otherwise).
- `Option Explicit` everywhere.
